# Triage-Labels

Die Skills sprechen von fünf kanonischen Rollen. Diese Tabelle bildet sie auf die Labels in diesem Repo ab.

| Rolle | Label hier | Bedeutung |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Muss noch bewertet werden |
| `needs-info` | `needs-info` | Wartet auf Rückmeldung |
| `ready-for-agent` | `ready-for-agent` | Vollständig beschrieben, ein AFK-Agent kann loslegen |
| `ready-for-human` | `ready-for-human` | Muss ein Mensch machen |
| `wontfix` | `wontfix` | Wird nicht umgesetzt |

Wenn ein Skill eine Rolle nennt, zum Beispiel „den AFK-Label setzen", nimm den Label-String aus dieser Tabelle.
